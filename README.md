# 目黒区 公共施設マップ

目黒区の区有施設（施設データ集R6の198棟）を地図に載せた単一HTML。築年度と敷地面積の範囲で絞り込み、駅圏・学区・町丁目別人口（2020・2050・2100）を重ね、再開発区域の多角形を描いて面積・人口・区有施設を計量できる。

- デモ：https://architech-lab.github.io/meguro-shisetsu-map/
- 背景地図：国土地理院タイル（外部通信あり）

## 読むときの注意
- 施設の位置は、固定資産台帳の所在地を国土地理院の住所検索で座標化したもの。区外・非公開住所の施設28件は未配置。公園等は名称照合の代表点で、建物の位置ではない。
- 人口は町丁目の平均密度による按分で、区域内の分布は一様と仮定した目安。2050・2100年は社人研・区推計をもとにした推計値。
- 描いた多角形はこのブラウザの localStorage に保存される。サイトデータを消すと失われるので、GeoJSONで書き出して控えを取ること。`data/redev_polygons.geojson` は作者が描いた例。

## 再現
`src/00〜07_*.py` が取得→GeoJSON→ジオコーディング→地図HTML。原本（区の施設データ集・固定資産台帳、国土数値情報、e-Stat、OSM）は再配布しない。
